# Работа с переводами

UI использует Qt Linguist catalogs в `src/skin_studio/i18n/locale/{en,ru}/skin_studio.ts`. Переводимые строки вызываются через `LanguageManager.text()` с Qt context `App`.

## Изменение каталога

1. Добавьте или измените исходную английскую строку в UI и оба `.ts` файла.
2. Заполните перевод для английского и русского каталогов.
3. Выполните `python scripts/compile_translations.py`.
4. Выполните `ruff check .` и `pytest`.
5. Для критических действий и ошибок добавьте проверку наличия обеих переводных строк в `tests/unit/test_translations.py`.

Скрипт вызывает `pyside6-lrelease -fail-on-unfinished`; незавершённые переводы прерывают сборку. Готовые `.qm` включены в Python package, чтобы запуск установленного приложения не зависел от наличия Qt Linguist на компьютере пользователя. Для новых языков добавьте locale каталог, строки, тесты и язык в `LanguageManager.SUPPORTED`.

Строки с параметрами переводятся целиком с placeholder, например `{count}`; не соединяйте переведённые фрагменты предложения. Каталоги должны оставаться UTF-8 и корректно обрабатывать кириллицу.
